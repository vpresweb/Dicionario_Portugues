# Dicionario_Portugues

Интерактивный словарь португальского языка, работает через web.

## Возможности

- поиск в обе стороны: PT → RU и RU → PT;
- поиск без учёта регистра и диакритики (`acao` найдёт `ação`);
- части речи, род, примеры употребления;
- спряжение глаголов во всех шести лицах (включая vós), повелительное наклонение, причастие и герундий;
- поиск по формам глагола (`fiz` найдёт `fazer`);
- ссылка на результат поиска (`?q=слово`);
- режим карточек для заучивания слов (`#cards`);
- тест на спряжение глаголов (`#quiz`);
- озвучивание: нажатие на любое португальское слово, форму глагола или пример произносит его.

Онлайн: https://vpresweb.github.io/Dicionario_Portugues/

## Структура

```

js/cards.js           режим карточек
js/quiz.js            тест на спряжение

data/dictionary.json  словарные статьи
tests/                автотесты (node --test)
```

## Формат статьи

```json
{
  "word": "casa",
  "pos": "noun",
  "gender": "f",
  "translations": ["дом", "жилище"],
  "examples": [{ "pt": "Vou para casa.", "ru": "Я иду домой." }]
}
```

`pos`: `noun`, `verb`, `adj`, `adv`, `prep`, `pron`, `conj`, `interj`, `num`, `phrase`. `gender` (`m`/`f`) и `examples` необязательны.

## Спряжение

Формы строятся по европейскому варианту португальского для лиц eu, tu, ele/ela/você, nós, vós, eles/elas/vocês.
Времена: presente, pretérito perfeito, pretérito imperfeito, futuro, condicional, presente do conjuntivo.

Повелительное наклонение (tu, você, nós, vós, vocês) строится автоматически: для tu и vós — форма presente
без конечного `-s` (`falas` → `fala`, `falais` → `falai`), для остальных — формы conjuntivo.
Отрицательное повелительное — `não` + conjuntivo (`não fales`).

Правильные глаголы на `-ar`, `-er`, `-ir` спрягаются автоматически, включая орфографические замены
(`ficar` → `fiquei`, `conhecer` → `conheço`). Для неправильных глаголов отличающиеся формы задаются
в поле `conjugation`, остальные генерируются:

```json
{
  "word": "fazer",
  "pos": "verb",
  "translations": ["делать"],
  "conjugation": {
    "presente": ["faço", "fazes", "faz", "fazemos", "fazeis", "fazem"],
    "imperativo": ["faz", "faça", "façamos", "fazei", "façam"],
    "participio": "feito"
  }
}
```

Ключи: `presente`, `perfeito`, `imperfeito`, `futuro`, `condicional`, `conjuntivo` (по шесть форм: eu, tu, ele, nós, vós, eles),
`imperativo` (пять форм: tu, você, nós, vós, vocês), `participio`, `gerundio`.

## Карточки

Вкладка «Карточки» показывает слово, по нажатию — перевод, род и пример. Каждое нажатие на карточку
произносит португальское слово. Ответ «Знаю» или «Не знаю» можно дать сразу, не переворачивая карточку
(клавиши → и ←, пробел — перевернуть). Повторение по системе Лейтнера: пять уровней, незнакомые слова
выпадают чаще, слово считается выученным с четвёртого уровня. Можно выбрать направление (PT → RU, RU → PT)
и часть речи. Переключатель «Озвучивать при перевороте» управляет озвучиванием при перевороте пробелом.
Прогресс и настройка хранятся в `localStorage` браузера.

## Тест на спряжение

Вкладка «Тест» показывает глагол, время и лицо (например, `fazer · Pretérito perfeito · nós`) —
нужно ввести форму. Ответ без нужной диакритики (`falamos` вместо `falámos`) засчитывается
с предупреждением. Правильный ответ озвучивается, ниже — счёт и серия верных ответов.
В настройках выбираются времена (включая повелительное), набор глаголов (все, неправильные,
правильные) и форма vós. Под полем ввода — кнопки для букв с диакритикой.

## Озвучивание

Используется встроенный синтез речи браузера (Web Speech API), без внешних сервисов. Голос выбирается
в порядке pt-PT → pt-BR → любой португальский. Если португальского голоса в системе нет, внизу страницы
появляется подсказка, а текст читает голос по умолчанию. В Windows голос pt-PT устанавливается в
«Параметры → Время и язык → Речь».

Озвучивается всё, что размечено классом `speak`: заголовок статьи (также по Enter), примеры,
формы спряжения, причастие, герундий и слова на карточках.

## Запуск

Приложение статическое, сборка не нужна. Словарь загружается через `fetch`, поэтому страницу нужно открывать через локальный сервер, а не как файл:

```
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Тесты

Автотесты используют встроенный в Node.js (20+) модуль `node:test`, зависимостей нет:

```
npm test
```

Проверяются генератор спряжения (правильные глаголы, орфографические замены, повелительное),
целостность `data/dictionary.json` (части речи, род, полнота таблиц, отсутствие повторов),
эталонные формы неправильных глаголов, поиск и логика теста. Тесты запускаются в GitHub Actions
при каждом push в `main`.
